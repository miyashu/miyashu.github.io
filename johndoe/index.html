SFORM16

sform16_007 Windows

MEGA-SCSI用 FAT16 マルチパーティション・フォーマッタ

FAT16 multi-partition formatter for MEGA-SCSI

MSX-DOS2とMEGA-SCSIで使うSDカードを、WindowsからFAT16のマルチパーティション構成でフォーマットします。形式はSFORM-2(V0.09a)のネイティブ形式(隠し領域の無い方)と同じで、各パーティションにMEGASCSI.TBLを作ります。SFORM-2はFAT12専用なので、大きなパーティションを使いたいときのためのツールです。

Formats SD cards for MSX-DOS2 and MEGA-SCSI from Windows, as multiple FAT16 partitions. The layout follows SFORM-2 (V0.09a) native format (the one without the hidden area), with a MEGASCSI.TBL in every partition. SFORM-2 itself only makes FAT12, so this tool is for when you want larger partitions.

できること

Features

  • 1パーティション 512MiB / 1GiB / 2GiB、合計2GiBまで
  • クラスタサイズは容量に合わせて自動で選択
  • --dry-run で書き込まずに計画だけ表示
  • --inspect でフォーマット済みの構造を検査
  • イメージファイルでの試験(管理者権限不要)
  • Partitions of 512 MiB, 1 GiB or 2 GiB, up to 2 GiB in total
  • Cluster size chosen automatically for each partition
  • --dry-run shows the plan without writing
  • --inspect checks an existing layout
  • Can format an image file for testing (no admin rights needed)

必要なもの

Requirements

  • Windows 10 / 11、管理者権限
  • Python 3.7以降(標準ライブラリのみ)
  • 32MiBより大きく32GiB以下のSDカード
  • Windows 10 / 11, administrator rights
  • Python 3.7 or later (standard library only)
  • An SD card larger than 32 MiB and up to 32 GiB
作業メモ — J.D.

依頼内容は「SFORM-2はFAT12しか作れないから、FAT16で大きなパーティションを作れるやつを」。ついでにSFORM-2・Nextorのパーティション形式の調査報告書まで書かされました。ダンプを取ってこいと言ったのは私ですが、取ってきたダンプの見出しを2か所間違え、別のカードのセクタを1つ紛れ込ませたのは依頼人です。

Work log — J.D.

The brief: "SFORM-2 only makes FAT12, so build me something that makes big FAT16 partitions." Then I got roped into writing a full survey of the SFORM-2 and Nextor partition formats as well. Yes, I asked for the sector dumps. No, I did not mislabel two of them or slip in a sector from a different card. That was the client.

注意: 物理ディスクに直接書き込みます。対象のカードの内容はすべて消えます。--list と --dry-run でディスク番号を必ず確かめてから実行してください。

Caution: this writes directly to the physical disk and erases everything on the target card. Always confirm the disk number with --list and --dry-run first. The program's messages and manual are in Japanese.

MCPLAYER

Ver 0.10 MSX ROM

MICRO CABIN MUSIC PLAYER — マイクロキャビンのゲーム音楽をメガロムで聴く

MICRO CABIN MUSIC PLAYER — Micro Cabin game music on a MegaROM

マイクロキャビンのゲームの曲を、MSXのROMカートリッジ(ASCII16メガロム)にまとめて聴くためのツールです。曲はそれぞれのゲーム自身のサウンドドライバと音色で鳴らします。配布物には曲・ドライバ・ゲームの画面などのデータは入っておらず、ご自分で持っているゲームのディスクイメージから取り出してROMを作ります。

A tool that builds an MSX MegaROM cartridge (ASCII16) for listening to the music of Micro Cabin games. Every song plays with the game's own sound driver and instruments. The package contains no Micro Cabin data; the music and drivers are extracted from your own disk images when you build the ROM.

対応ゲーム

Supported games

  • Xak、Xak II、ガゼルの塔
  • FRAY(MSX2版 / turboR版)
  • 幻影都市、ファイナルファンタジー
  • キャンペーン版大戦略II、プリンセスメーカー
  • The Tower of Cabin
  • Xak, Xak II, Tower of Gazzel
  • Fray (MSX2 / MSX turboR)
  • Illusion City, Final Fantasy
  • Dai Senryaku II (Campaign Version), Princess Maker
  • The Tower of Cabin

プレーヤー

Player

  • MSX1 / 2 / 2+ / turboR、RAM 32KB以上
  • MSX-MUSIC・FM-PACを自動で検出(無ければPSGのパートだけ)
  • MSX2以降ではゲームのCGを表示、V9990にも対応
  • レベルメーター、ループ回数・再生範囲の切り替え、自動再生
  • 実機ではFS-A1GT(turboR)+ESERAMair(WiFi付き似非RAMディスク、ASCII16)で起動・再生を確認
  • MSX1 / 2 / 2+ / turboR, 32 KB RAM or more
  • Finds MSX-MUSIC or FM-PAC (PSG parts only without FM)
  • Shows game pictures on MSX2 and later, and on V9990
  • Level meters, loop count and play-range modes, autoplay
  • Tested on real hardware: FS-A1GT (turboR) with an ESERAMair (WiFi ESE-RAM cartridge, ASCII16)

ROMを作るのに必要なもの

To build the ROM

  • Python 3.8以降とPillow
  • ゲームのディスクイメージ(.dsk)
  • Python 3.8 or later with Pillow
  • Disk images (.dsk) of your games
作業メモ — J.D.

依頼内容は「マイクロキャビンの曲を、それぞれのゲーム自身のドライバで鳴らすメガロムを」。できあがった頃に「やっぱりマイクロキャビンのコードは配布物に入れたくない」と言い出したので、ドライバをユーザーのディスクから取り出して手を入れる方式に作り直しました。ドライバ10版、全255曲で動作を確認済み。依頼人いわく「音そのものは耳でまだ十分に確かめていない」そうです。私の仕事は終わっています。

Work log — J.D.

The brief: "A MegaROM that plays Micro Cabin music with each game's own sound driver." Right when it was done, the client decided no Micro Cabin code should ship in the package, so I rebuilt it to pull the drivers out of the user's own disks and patch them at build time. Ten driver versions, all 255 songs checked. The client admits they "haven't properly listened to it yet." My part is finished.

著作権: 曲・ドライバ・ゲームの画面の著作権はマイクロキャビンにあります。作ったROMは個人で楽しむ範囲で使い、配布しないでください。
