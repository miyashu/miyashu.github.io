NM (Next Maintenance) Manual

v0.99n (evaluation version, 2026-11-23). NM is a file maintenance tool with two screens, left and right, for MSX-DOS2 and Nextor. The name NM stands for Next Maintenance: a file maintenance tool with another screen next to the first.

NM takes over the operation of MultiMente (MM, by MOGU) and is newly written. It does not use any of MM's program code. MM's settings can be used as they are: NM reads MM's MMRET.DAT and MMMCR.DAT, and the lines of MM.CFG can be copied into NMCFG.DAT.

This is an evaluation version, so some parts have not been fully tested. On an important disk, make a backup before you try any operation that writes to the disk. In particular, try [Y] (writing the order) and [P] (partition switching) on a disk that you can afford to lose. The differences from MM are described in the separate document "MM-COMPARE_en".

Using NM without kanji (ANK mode)

NM can show Japanese (Shift-JIS) full-width characters, but it does not need to. With KANJI = OFF in NMCFG.DAT, NM runs in "ANK mode": every byte, including characters of 80h and above, is shown as one character with the machine's own font. All of NM's own messages on the screen are in English.

  1. The default is KANJI = AUTO. On a machine that is not a Japanese model, NM already runs in ANK mode without any setting.
  2. On a Japanese machine (including an emulated one), switch kanji off yourself. NMCFG.DAT is a text file in the same directory as NM.COM. The one in the package has every line commented out with ;. Add this line (or uncomment the existing line and change it): 
    KANJI = OFF
  3. Check which mode is running. Look at the last character of the title at the top left of the frame: NM v0.99n_A means ANK only, NM v0.99n_K means kanji.

In ANK mode NMFONT.DAT and NMUNI.DAT are not used and are not needed.

NMCFG.DATonly if you want settingsonly if you want settings

Two more points:

  • In ANK mode, characters in long file names that are not ASCII appear as ?.
  • [¥] in this manual is the key of character code 5Ch: the backslash key on keyboards that are not Japanese.
  • Keys such as [SHIFT]+[1]-[8] depend on the keyboard layout. If a key does not do what this manual says on your keyboard, see KEYMAP in chapter 9 (settings).

Files that are not there, and all files when the variable is not set, are read from the same place as the program. 3. Starting and quitting

NM [left side] [right side]

With no arguments, NM shows the drive and directory it was started from on both the left and the right. If you write locations after the name, the left side and then the right side start there. You can leave out the right side only.

FormMeaning
A:The current directory of that drive
A:\UTILSDrive and directory
\UTILSA directory on the drive NM was started from
UTILSA directory below the directory NM was started from
NM A: B:            left is A:, right is B:
NM A:\UTILS         left is A:\UTILS, right is the starting location

A side for which you wrote a drive that does not exist, or something that is not a directory, becomes the starting location. When NM comes back after running an external command, these arguments have no effect (it starts from the directory at that time).

Quit with [Q] or [ESC]. [ESC] asks for confirmation. When NM quits, the drive and directory of the side that was active become the current ones of DOS.

  • The name and version appear at the top left of the frame (NM v0.99n_K). The last character is K when NM handles kanji, and A when it is ANK only (KANJI = OFF). When you report a problem, please include this text.
  • The left and right halves are called "sides". The side with the white bar (the cursor) is the active side.
  • The bottom line is a guide to the keys. While [SHIFT] is held down, it changes to a guide to the keys used together with [SHIFT] ([TAB], [SPACE], [F8]-[F10] = [F3]-[F5] with [SHIFT]).
  • A * at the left edge of the list is a mark.
  • The line below the list shows the total of the marked files in KB (for example 46 marked 372K). You can compare it with the free space of the copy destination. The value is the total number of bytes rounded up to a whole KB, and the contents of directories are not added. If the clusters of the destination are large, the files actually take more space than this.
  • The +N after it is the sort state (+ ascending, - descending; N name, S size, D date, E extension). * means the list has been reordered by hand and not yet written to the disk. W means a display filter is in effect.
  • The free space is not shown when a Z80 machine is looking at a large drive (because counting it takes time). This can be changed in the settings.

If there are marks, the operation applies to all marked entries; if there are none, it applies to the file under the cursor. A directory is handled together with its contents.

[N]Rename

  • When a file of the same name exists, choose [Y] overwrite / [N] skip / [T] only if newer / [C] change the name / [ESC] abort. [Y] [N] [T] with [SHIFT] apply to all the following files. With [C], type the name to use at the destination (if that name also exists, NM asks again).

  • During a copy, [ESC] interrupts it.
  • The destination file of a copy is not given a long file name (it has only an 8.3 name).

  • After an operation, only the side whose contents changed is read again (for copy, the destination; for delete and rename, the active side; for move, both).

Sorting and reordering

KeyDescription

Reorder mode ([DEL])

This works the same way as in MM. You take files out of the list and put them back where you want them.

KeyDescription
[DEL]Take the file under the cursor out of the list. The files taken out are lined up in the 3 lines above the list (where Path, Name and Size normally appear). Up to 18 files
[INS]Put the file that was taken out last, among the files taken out, in front of the file under the cursor. The cursor lands on the file just put in, so pressing the key repeatedly restores the order the files had before they were taken out
[↑][↓][←][→]Move the cursor (the same with [SHIFT]). The cursor can go one line below the last file (to put files at the end)
[ESC]If files taken out remain, give up the reordering and read that side again
  • Pressing [DEL] in the list takes out the file under the cursor and enters this mode.
  • The mode ends when all the files taken out have been put back.
  • If you press [DEL] several times without moving the cursor and then press [INS] the same number of times, the original order is restored.
  • .. cannot be taken out. Nothing can be put in front of .. either.
  • While in this mode, the other keys have no effect. The list on the other side stays as it is.

Cautions for [Y]

  • The bottom line turns into a red warning, and NM writes only when you press [Y] once more. Any other key does nothing.
  • The directory is rewritten directly. If the power is cut or the disk is removed during the write, the directory may be damaged.
  • NM can handle directories of up to 192 slots (192 files without long names; fewer when there are long names). A larger directory is refused and nothing is written.
  • If the write fails, NM writes back the original contents and then shows a message asking you to check the disk.
  • Entries that are not in the list (such as files hidden by the display filter) follow at the end in their original order.

When an external command is run, NM starts again after the command ends. The drives and directories of the left and right sides, the cursor position and the active side are restored to what they were before the run. Marks, the order and the filter on the files shown are not restored. (During the run, the locations are held in the environment variables NM_L, NM_R, NM_A and NM_C. NM reads them when it starts again and deletes them.)

During the run, only a small part of NM (512 bytes) stays in memory.

  • If the first word of the command is a .COM file, NM starts that file directly. The memory available to the program (TPA) is only 512 bytes less than when it is started from the prompt. The file is searched for in the same order as the shell does: if a path is written, only there; if not, the current directory, then the directories of %PATH%.
  • Everything else is run through the shell (%SHELL%): the shell's own commands such as DIR and TYPE, batch files, lines that contain < > | %, and anything that was not found. In this case the shell also stays in memory, so the TPA is a further 1 to 1.5KB smaller.
  • When several commands are run at once (the macros $R and $T), everything after a command that went through the shell also goes through the shell.

Text input

When you type a name or a command, when NM asks for confirmation and when it reports an error, a window opens in the centre of the screen. When you press a key the window disappears and the display under it is restored. The key guide and the progress of copies and other operations appear on the bottom line as before.

These keys can be used on the input line. It holds up to 60 characters.

KeyDescription
[←] [→]Move the cursor
[BS]Delete the character to the left of the cursor
[DEL]Delete the character at the cursor
[INS]Switch between insert and overwrite. In insert the cursor is a line under the character; in overwrite it is the size of a character
[CTRL]+[SPACE]Start / stop kanji conversion (MSX-JE)
[RETURN] / [ESC]Accept / cancel

Input starts in insert. A full-width character is handled as one character. In [X] and [R] the letters you type are passed as they are (lower case stays lower case). In other inputs they become upper case. Where you type the name of a file or directory, a name that does not fit in 8 + 3 characters is not accepted (one full-width character counts as 2 characters). After a window tells you so, you return to the input line and can correct it.

Kanji conversion (MSX-JE)

On models with built-in MSX-JE (FS-A1ST, FS-A1GT and others), or when an MSX-JE cartridge is present, kanji conversion can be used on the input line.

  • Start it with [CTRL]+[SPACE]. MSX-JE appears on the bottom edge of the window frame, and the line below the input line becomes the conversion line.
  • Operation is the usual MSX-JE procedure: type the reading, convert with [SPACE], confirm with [RETURN]. The confirmed characters are entered at the cursor position of the input line. When you confirm one phrase at a time, the confirmed part moves to the input line and the candidates for the remaining phrases appear on the conversion line.
  • Press [CTRL]+[SPACE] again to stop. When there are no characters being converted, [RETURN] and [ESC] work as keys of the input line, so the input window closes and MSX-JE ends too.
  • When KANJI = OFF, and when there is not enough free space in the upper part of memory (for example when there are many resident programs), pressing [CTRL]+[SPACE] does not start it.

7. Partition switching ([P])

Assigns a different partition to the drive of the active side. Choose from the list with the cursor or a digit key. [ESC] cancels.

EnvironmentDescription
NextorLists the partitions of the devices connected to the same driver as that drive. The current one is marked (now), and one already assigned to another drive shows that drive name
MEGA-SCSI on MSX-DOS2Lists the contents of MEGASCSI.TBL in the root of that drive. The hidden area of the ESE ASPI format (number 0) is not shown
  • The drive that holds the NM program cannot be switched (NM refuses). If the NM files were not on the partition switched to, NM could not continue.
  • The list holds up to 14 entries.
  • On Nextor, if you choose a partition already assigned to another drive, a Nextor error appears and nothing changes.
  • On a drive that is not a target, such as a floppy, NM only says so.

8. Working with MGSDRV and MCPLAYER

This can be used when MGSDRV is resident (or when MCPLAYER has loaded MGSDRV: see "MCPLAYER" below). MGSDRV does the playing, so the music continues while you operate NM and after NM quits.

KeyDescription

Song data can be up to 16KB. When MGSDRV is not resident, [RETURN] on a .MGS file is handled as for an ordinary file.

MCPLAYER (Micro Cabin songs)

When the resident MCPLAYER is there (MCPLAYER /Z makes it resident), .MCM songs can be played in the same way.

KeyDescription
[RETURN] (on a .MCM file)Load that song and play it
[G]While MCPLAYER is playing: show the title of the song (or, without one, its file name and the name of the driver). Pressing [S] there stops the playing
  • Driver file (.DRV): put it in the directory of the song or in the directory of NM.COM. NM looks for xxx.DRV with the first 5, 4, then 3 characters of the song's file name (for XAK201.MCM: XAK20.DRV, XAK2.DRV, XAK.DRV). If none is found, it looks through the .DRV files in the directory of the song for one that knows the song (for songs that were renamed).
  • Song list (.LST): if the directory of the song has a song list of MCPLAYER (XAK.LST and the like), NM takes the title, the driver and the number of loops from it. The title is shown as "game / title": in Japanese when NM handles kanji, in English when it is ANK only. A driver named in the list is used before the ones found by the file name.
  • Size: a song can be up to 6KB.
  • When MGSDRV is resident too: starting a song with one of them stops the other.
  • Letting MCPLAYER load MGSDRV (MCPLAYER 0.37 or later): made resident with MCPLAYER /M /Z, MCPLAYER loads the MGSDRV.COM of its own directory and does the work of MGSDRV as well. Both .MGS and .MCM songs can be played without making MGSDRV resident, and DOS restarts only once. NM is used in the same way as with the two resident separately.
  • When MCPLAYER is not resident, [RETURN] on a .MCM file is handled as for an ordinary file.

Setting the clock (ESERAMair)

With NTP = ON, NM gets the time from the ESERAMair once, when it starts, and sets the clock of DOS. The default is OFF.

This feature is based on how the ESERAMair is implemented at present. It may change, or stop working, when the ESERAMair changes in the future.

ItemDescription
NTPON / OFF
NTP_SLOTThe slots to look for the ESERAMair in (for example 1, 2-3). Write it only when the ESERAMair is not found
TZThe time zone of your region (for example +9:00, -5). Write it only when you are not in Japan
NTP_TZThe time zone of the time the ESERAMair gives (default +9:00)
DSTSummer time. ON makes it one hour later

How the ESERAMair is looked for

  1. When the Nextor for the ESERAMair is running, NM uses the slot that this Nextor reports (the TCP/IP UNAPI implementation named ESERAMair). Nothing is written to the cartridge.
  2. Otherwise NM looks at the slot that handles the drive NM was started from.
  3. If it is still not found, NM looks at the slots written in NTP_SLOT, in the order they are written.

How to write NTP_SLOT:

  • A list of numbers, separated by commas or spaces. Examples: NTP_SLOT = 1, 2, NTP_SLOT = 2-3. Up to 23 characters.
  • A primary slot alone, such as 1, means all four of 1-0 to 1-3 when the slot is expanded. 2-3 is that expanded slot only.
  • The search stops at the first one found.

Cautions

  • In cases 2 and 3, NM writes to the bank register (6000h) of the slot to find out whether it is an ESERAMair. It puts the value back afterwards, but do not write the slot of a cartridge that is not an ESERAMair in NTP_SLOT.
  • The time is received by talking to the microcontroller inside the ESERAMair. Meanwhile a part of the cartridge's SRAM (512 bytes) is overwritten for a moment and put back at the end. If the machine is reset or switched off in between, that part stays overwritten.
  • When the ESERAMair is set to write protect, or to a bank mode other than ASCII 8K / 16K, the time cannot be read (NM waits a few seconds and then starts as usual).
  • It is made to work whatever the SRAM holds (an ESE RAM disk, the Nextor for the ESERAMair, and so on), but it was checked on real hardware only with an ESE RAM disk.

12. When you change a disk or card

NM does not check by itself whether a disk or SD card has been changed. The screen keeps the contents from the last time it was read. After changing one, press [0]. NM reads the lists of both sides, the volume name and the free space again, and shows both from the top. At this time it also makes DOS discard the disk contents that DOS remembers.

  • It is DOS (and the driver) that notices the change. The next time that drive is read or written, DOS treats it as a new disk. Whether a card change is reported to DOS depends on the driver of the interface.
  • Even before you press [0], if you change directory or do a file operation, the disk is read again at that point. However, you would be choosing files from the old list left on the screen, so it is safer to press [0] first.
  • If you remove the disk that holds the NM program, NM.OVL, NMFONT.DAT and NMUNI.DAT can no longer be read. Put the program on a drive that is not removed (a RAM disk, for example).
  • Do not remove a disk in the middle of a copy or other operation.

Using one drive as two drives

On a machine with one floppy drive, DOS gives the one drive two drive names (A: and B:; with other interfaces present they may be D: and E:, and so on). When NM tries to read or write the other drive name, the following prompt appears in the middle of the screen.

 Insert disk for drive B: and press a key

Change to the disk that you use under that drive name and press any key. The prompt disappears and the operation continues. When you open A: and B: on the left and right and copy, this prompt appears every time the reading side and the writing side change over.

Screen saver

If no key is pressed on the list screen for the time set by SC_TIME, the screen saver starts. It does not start while an input or confirmation window is shown, inside the viewer, or during a copy or other processing.

  • Built-in (when SCSAVER is not written): The screen is divided into 16 pieces, one piece is made black, and a neighbouring piece slides into it; this is repeated. Pressing any key returns to the original screen. The list, the cursor and the marks stay as they were. The key pressed to stop it does not act as an operation.
  • External (SCSAVER = program name): NM starts a program that "starts, and ends when a key is pressed", such as a screen saver for MultiMente. When it ends, control returns to NM, and the locations of the left and right sides and the cursor are as before (marks are cleared). The disk is read every time it starts.
  • To turn it off, write SC_TIME = 0.

13. Limits and things not done yet

  • The list can show up to 819 entries per side (409 each when there is no free mapper RAM).
  • The viewer handles up to about 3000 lines. The viewer has no modes (such as showing control codes).
  • The clock is 24-hour display only.
  • [P] cannot specify a partition directly by number.
  • Half-width letters in a volume name become upper case.
  • On floppies, showing long file names with many kanji, and UTF-8 text, takes time (because NMUNI.DAT is read for every character).
