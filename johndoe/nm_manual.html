NM(Next Maintenance)取扱説明書

v0.99e(評価版、2026-11-21)。MSX-DOS2 と Nextor で動く、左右 2 画面のファイル管理ツールです。名前の NM は Next Maintenance の略で、「隣にもう 1 つの画面があるファイル整理の道具」という意味です。

  • 13. 制限と、まだ出来ていないこと
  • 14. 確認の状況
  • 15. 使っているもの

MultiMente(MM、MOGU 氏作)の操作を引き継いで、新しく書いたものです。MM のプログラムは使っていません。MM の設定はそのまま使えます: MMRET.DAT と MMMCR.DAT は MM のものを読み、MM.CFG の行は NMCFG.DAT へ写せます。

評価版なので、動作を確かめきれていない部分があります。大事なディスクでは、書き込みを伴う操作を試す前にバックアップを取ってください。とくに Yと Pは、消えてもよいディスクで試してください。MM との違いは「MM-COMPARE」にあります。

項目内容
本体MSX2 以上、VRAM 128KB、マッパー RAM 128KB 以上
OSMSX-DOS2、Nextor(2.1 と 3.0 で確認)。MSX-DOS1 では、メッセージを出して終了します
漢字本体の漢字 ROM、または同梱の NMFONT.DAT。MSX-View の漢字 ROM(View フォント)があれば、それを使います

おもに turbo R で試しています。Z80 の本体や 128KB の本体でも動く作りですが、確認が少ない状態です。

MMRET.DAT と MMMCR.DAT は MM と同じ書式です。MM のものがそのまま使えます(同梱はしていません)。お持ちでない時は、GIGAMIX さんのサイト(https://www.gigamix.jp/)から MultiMente をダウンロードすると、その中に入っています。NM だけ別の内容にしたい時は、同じ書式で NMRET.DAT、NMMCR.DAT という名前のファイルを作ってください。そちらが先に使われます。

DAT ファイルは、環境変数 %MM% にディレクトリを設定しておくと、そこから読みます。そこに無いファイルと、設定が無い時は、本体と同じ場所から読みます。NMRET.DAT と NMMCR.DAT を探す順は、%MM% の NM の名前、本体の場所の NM の名前、%MM% の MM の名前、本体の場所の MM の名前です。

3. 起動と終了

NM [左側] [右側]

何も付けなければ、起動時のドライブとディレクトリを、左右の両方に表示します。うしろに場所を書くと、左側、右側の順にそこから始まります。右側だけを省くこともできます。

書き方意味
A:そのドライブの、いまのディレクトリ
A:\UTILSドライブとディレクトリ
\UTILS起動時のドライブのディレクトリ
UTILS起動時のディレクトリの下のディレクトリ
NM A: B:            左が A:、右が B:
NM A:\UTILS         左が A:\UTILS、右は起動時の場所

無いドライブや、ディレクトリでないものを書いた側は、起動時の場所になります。外部コマンドを実行して戻ってきた時は、この指定は効きません(その時のディレクトリから始まります)。

終了は [Q] か [ESC] です。[ESC] は確認を求めます。終了すると、操作していた側のドライブとディレクトリが DOS のカレントになります。

  • 枠の左上に、名前と版が出ます(NM v0.99e_K)。最後の文字は、K が漢字を扱う状態、A が ANK 専用(KANJI = OFF)です。不具合を知らせる時は、この表示を添えてください。
  • 左右を「サイド」と呼びます。白い帯(カーソル)のある側が、操作している側です。
  • 最下行はキーの案内です。[SHIFT] を押している間は、[SHIFT] と一緒に使うキー([TAB]、[SPACE]、[F8]〜[F10] = [SHIFT] 併用の [F3]〜[F5])の案内に替わります。
  • 一覧の左端の * はマークです。
  • 一覧の下の行には、マークしたファイルの合計が KB で出ます(例 46 marked 372K)。コピー先の空き容量と見比べられます。バイト数の合計を 1KB 単位に切り上げた値で、ディレクトリの中身は足しません。コピー先のクラスタが大きいと、実際にはこれより多く使います。
  • そのうしろの +N はソートの状態です(+ 昇順、- 降順。N 名前、S サイズ、D 日付、E 拡張子)。* は手で並べ替えたまま、まだディスクに書いていない印、W は表示フィルタが効いている印です。
  • 空き容量は、Z80 の本体で大きなドライブを見ている時は出しません(数えるのに時間がかかるため)。設定で変えられます。

ファイル操作

マークがあればマークしたもの全部に、無ければカーソルのファイルに効きます。ディレクトリは中身ごと扱います。

キー内容
[C]コピー。行き先を入力します(反対側のパスが入った状態から始まるので、そのまま [RETURN] で反対側へ)
[M]移動。行き先の入力は [C] と同じ
[D]削除。確認があります。中身のあるディレクトリは件数を示して確認します
[N]名前の変更
[K]ディレクトリの作成
[A]属性と日時の変更。[R][H][S][A] で属性を切り替え、[D] で日時を入力、[RETURN] で設定
  • 同じ名前のファイルがある時は、[Y] 上書き / [N] 飛ばす / [T] 新しい時だけ / [C] 名前を変える / [ESC] 中止 を選びます。[Y] [N] [T] は、[SHIFT] 併用で以降すべてに適用します。[C] では、コピー先での名前を入力します(その名前もあれば、もう一度聞きます)。
  • 読み取り専用のファイルを消す、上書きする時は、その前に確認します。
  • コピー中は [ESC] で中断できます。
  • コピー先のファイルには長いファイル名を付けません(8.3 形式の名前だけになります)。
  • 長いファイル名を持つファイルを削除、名前変更、移動した時は、ディスクに残る長い名前の部分も消します(消さないと、Windows で壊れた名前に見えたり、MSX-DOS2 でディレクトリを消せなくなったりするためです)。
  • 操作のあとは、中身が変わった側だけを読み直します(コピーはコピー先、削除や名前変更は操作した側、移動は両方)。

並べ替え

キー内容
[S]操作している側をソート。続けて [N] 名前、[S] サイズ、[D] 日付、[E] 拡張子、[O] なし。文字を [SHIFT] 併用で押すと降順
[SHIFT]+[S]両側をソート
[DEL]並びかえモード(下の「並びかえモード」)
[Y]いまの一覧の並びを、ディスクのディレクトリに書き込む
[SHIFT]+[Y]両側の並びを、それぞれのディレクトリに書き込む
  • [S] と [DEL] は画面の上だけの並べ替えです。ディスクは [Y] を押すまで変わりません。
  • ソートでは、ディレクトリがファイルより前に来ます。.. は先頭のままです。
  • [DEL] で並べ替えると、その側のソートは「なし」になり、一覧の下の行に * が出ます。この並びは、その側を読み直すと消えます。
  • NEXTOR.SYS などを先頭に置いたまま残りを並べたい時は、[S] でソートし、[DEL] でそれらを取り出して先頭へ入れ直してから [Y] を押します。

並びかえモード([DEL])

MM と同じやり方です。ファイルを一覧から取り出しておき、入れたい場所へ入れ直します。

キー内容
[DEL]カーソルのファイルを一覧から取り出す。取り出したものは、一覧の上の 3 行(ふだん Path、Name、Size が出る所)に並びます。18 個まで
[INS]取り出してあるファイルのうち、最後に取り出したものを、カーソルのファイルの前に入れる。カーソルは入れたファイルに乗るので、続けて押すと、取り出す前と同じ順に並びます
[↑][↓][←][→]カーソル移動([SHIFT] 併用も同じ)。いちばん下のファイルの、さらに 1 行下まで動かせます(末尾に入れるため)
[ESC]取り出したものが残っている時は、並べ替えをやめて、その側を読み直します
  • 一覧で [DEL] を押すと、カーソルのファイルを取り出して、このモードに入ります。
  • 取り出したものを全部入れ終わると、モードは終わります。
  • カーソルを動かさずに [DEL] を何回か押し、同じ回数だけ [INS] を押すと、元の並びに戻ります。
  • .. は取り出せません。.. の前に入れることもできません。
  • このモードの間、ほかのキーは効きません。反対側の一覧はそのままです。

[Y] の注意

  • 最下行が赤い警告になり、もう一度 [Y] を押した時だけ書き込みます。ほかのキーでは何もしません。
  • ディレクトリを直接書き換えます。書き込みの途中で電源が切れたり、ディスクを抜いたりすると、ディレクトリが壊れるおそれがあります。
  • 扱えるのは 192 スロットまでのディレクトリです(長い名前の無いファイルで 192 個。長い名前があるとその分少なくなります)。それより大きいディレクトリは断り、何も書きません。
  • 書き込みに失敗した時は、元の内容を書き戻してから、ディスクの検査を促すメッセージを出します。
  • 一覧に出ていないもの(表示フィルタで隠れたファイルなど)は、元の順のまま、うしろに続きます。

実行

キー内容
[RETURN]MMRET.DAT に従って実行(10 章)。当てはまる行が無ければ内蔵ビューア
[SHIFT]+[RETURN] / [CTRL]+[RETURN] / [SHIFT]+[CTRL]+[RETURN]NMCFG.DAT の S_TOOL / C_TOOL / SC_TOOL を起動
[V]内蔵ビューア(6 章)

[E]エディタ(EDITOR、既定は KID $F)でカーソルのファイルを開く。ファイル名の入った入力欄が出るので、そのまま [RETURN] を押す。名前の後ろにエディタのオプションを足すこともできる(入力した全体が $F になる)
[SHIFT]+[E]ファイル名を入力して、新しいファイルをエディタで開く
[R]カーソルのファイル名が入った入力行を出します。.COM と .BAT は名前の後ろに空白が付き、そこへ引数を書き足せます。ほかのファイルとディレクトリは名前だけが入り、カーソルは先頭です(前にコマンドを書けます)。[RETURN] で実行し、終わるとキー入力を待ちます
[X]コマンド行を入力して実行。マクロ(10 章)が使えます
[GRAPH]MMMCR.DAT のマクロの一覧を窓に出す。キーを 1 つ押すと実行、[ESC] で閉じる

外部コマンドを実行すると、終了後に NM が起動し直します。左右のドライブとディレクトリ、カーソルの位置、操作していた側は、実行の前と同じに戻ります。マーク、並び順、表示するファイルの絞り込みは元に戻りません。(実行の間、場所は環境変数 NM_L、NM_R、NM_A、NM_C に入っています。起動し直した時に読んで消します。)

実行中は、NM の小さな部分(512 バイト)だけがメモリに残ります。

  • コマンドの先頭の語が .COM ファイルなら、そのファイルを直接起動します。プログラムが使えるメモリ(TPA)は、プロンプトから起動した時より 512 バイト少ないだけです。ファイルは、シェルと同じ順に探します: パスを書いた時はそこだけ、書かない時はカレントディレクトリ、次に %PATH% のディレクトリ。
  • それ以外はシェル(%SHELL%)を通して実行します: DIR や TYPE などシェル自身のコマンド、バッチファイル、< > | % を含む行、見つからなかったもの。この時はシェルもメモリに残るので、TPA はさらに 1〜1.5KB 少なくなります。
  • 1 回に複数のコマンドを実行する時(マクロの $R や $T)は、シェルを通したコマンドより後ろも、すべてシェルを通します。

文字の入力

名前やコマンドを入力する時、確認を求める時、エラーを知らせる時は、画面の中央に窓が開きます。キーを押すと窓は消え、下の表示は元に戻ります。キーの案内と、コピーなどの進み具合は、今までどおり最下行に出ます。

入力行で使えるキーです。60 文字まで入ります。

キー内容
[←] [→]カーソルを動かす
[BS]カーソルの左の 1 文字を消す
[DEL]カーソルの位置の 1 文字を消す
[INS]挿入と上書きを切り替える。挿入の時のカーソルは文字の下の線、上書きの時は文字の大きさ
[CTRL]+[SPACE]漢字変換(MSX-JE)を始める / やめる
[RETURN] / [ESC]決定 / 取り消し

初めは挿入です。全角の文字は 1 文字として扱います。[X] と [R] では打った英字がそのまま(小文字は小文字で)渡ります。ほかの入力では大文字になります。ファイルやディレクトリの名前を入力する所では、8 + 3 文字に入りきらない名前は受け付けません(全角の 1 文字は 2 文字分です)。知らせる窓が出たあと、入力行に戻って直せます。

漢字変換(MSX-JE)

MSX-JE を内蔵した機種(FS-A1ST、FS-A1GT など)や、MSX-JE のカートリッジがある時は、入力行で漢字変換ができます。

  • [CTRL]+[SPACE] で始めます。窓の枠の下辺に MSX-JE と出て、入力行の下の行が変換用の行になります。
  • 読みを打ち、[SPACE] で変換、[RETURN] で確定、という MSX-JE のいつもの操作です。確定した文字は、入力行のカーソルの位置に入ります。文節ごとに確定していく時は、確定した分が入力行へ移り、残りの文節の候補が変換用の行に出ます。
  • もう一度 [CTRL]+[SPACE] でやめます。変換中の文字が無い時の [RETURN] や [ESC] は入力行のキーとして働くので、入力の窓が閉じ、MSX-JE も終わります。
  • KANJI = OFF の時と、メモリの上のほうに空きが足りない時(常駐プログラムが多い時など)は、[CTRL]+[SPACE] を押しても始まりません。

7. パーティション切替([P])

操作している側のドライブに、別のパーティションを割り当てます。一覧からカーソルか数字キーで選びます。[ESC] で取り消しです。

Nextorそのドライブと同じドライバにつながっているデバイスのパーティションを並べます。いまのものに (now)、ほかのドライブに割り当て済みのものにはそのドライブ名が出ます
MSX-DOS2 の MEGA-SCSIそのドライブのルートにある MEGASCSI.TBL の内容を並べます。似非 ASPI 形式の隠し領域(0 番)は出しません
  • NM 本体のあるドライブは切り替えられません(断りが出ます)。切り替えた先に NM のファイルが無いと、続けられなくなるためです。
  • 一覧は 14 件までです。
  • Nextor で、ほかのドライブに割り当て済みのパーティションを選ぶと、Nextor のエラーが出て何も変わりません。

8. MGSDRV との連携

MGSDRV が常駐している時に使えます。演奏は MGSDRV が行うので、NM の操作中も、終了したあとも鳴り続けます。

曲データは 16KB までです。MGSDRV が常駐していない時、.MGS の上の [RETURN] はふつうのファイルと同じ扱いになります。

11. 長いファイル名と漢字

  • 長いファイル名(LFN): Windows などで付けた長い名前を、カーソルを止めた時に Name の行へ出します(キーを押し続けて動かしている間は 8.3 形式の名前です)。表示だけで、入力や変更はできません。一覧と操作は 8.3 形式の名前で行います。FAT12 と FAT16 が対象です。

    2. NMFONT.DAT(美咲フォント 8×8)
    3. 漢字 ROM の字を 12×8 に縮小したもの

12. ディスクやカードを入れ替えた時

NM は、ディスクや SD カードが入れ替わったことを自分では調べません。画面は、最後に読んだ時の内容のままです。入れ替えたあとは [0] を押してください。両側の一覧、ボリューム名、空き容量を読み直し、どちらも先頭から表示します。このとき、DOS が覚えているディスクの内容も捨てさせます。

  • 入れ替えに気づくのは DOS(とドライバ)です。次にそのドライブを読み書きした時に、DOS が新しいディスクとして扱います。カードの入れ替えを DOS に知らせるかどうかは、インターフェースのドライバによります。
  • [0] を押す前でも、ディレクトリの移動やファイル操作をすれば、その時点でディスクから読み直します。ただし、画面に残っている古い一覧を見てファイルを選ぶことになるので、先に [0] を押すほうが安全です。
  • NM 本体のあるディスクを抜くと、NM.OVL、NMFONT.DAT、NMUNI.DAT が読めなくなります。本体は、抜かないドライブ(RAM ディスクなど)に置いてください。
  • コピーなどの操作の途中では抜かないでください。

1 台のドライブを 2 つのドライブとして使う時

フロッピーのドライブが 1 台の本体では、DOS が 1 台のドライブに 2 つのドライブ名を付けます(A: と B:。ほかのインターフェースがあると D: と E: などになります)。もう一方のドライブ名を読み書きしようとすると、画面の中ほどに次の案内が出ます。

 Insert disk for drive B: and press a key

そのドライブ名で使うディスクに入れ替えて、何かキーを押してください。案内は消えて、続きの操作に戻ります。左右に A: と B: を開いてコピーする時は、読む側と書く側が替わるたびにこの案内が出ます。

スクリーンセーバー

一覧の画面で SC_TIME の時間だけキーを押さずにいると、スクリーンセーバーが始まります。入力や確認の窓が出ている間、ビューアの中、コピーなどの処理中は始まりません。

  • 内蔵のもの(SCSAVER を書いていない時): 画面を 16 枚に分け、1 枚を黒くして、隣の 1 枚をそこへ滑らせる動きを繰り返します。何かキーを押すと元の画面に戻ります。一覧、カーソル、マークはそのままです。止めるために押したキーは、操作としては働きません。
  • 外部のもの(SCSAVER = プログラム名): MultiMente 用のスクリーンセーバーなど、「起動して、キーが押されたら終わる」プログラムを起動します。終わると NM に戻り、左右の場所とカーソルは元のとおりです(マークは消えます)。起動のたびにディスクを読みます。
  • やめたい時は SC_TIME = 0 と書きます。

13. 制限と、まだ出来ていないこと

  • 一覧に出せるのは 1 サイド 819 件までです(空きのマッパー RAM が無い時は 409 件ずつ)。
  • ビューアの行数は約 2500 行までです。ビューアのモード(コントロールコードの表示など)はありません。
  • 時計は 24 時間表示だけです。
  • [P] は、パーティションを番号で直接指定することはできません。
  • ボリューム名の半角の英字は大文字になります。
  • フロッピーでは、漢字の多い長いファイル名や UTF-8 のテキストの表示に時間がかかります(1 字ごとに NMUNI.DAT を読むため)。
