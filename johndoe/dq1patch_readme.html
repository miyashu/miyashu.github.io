MSX2 版ドラゴンクエスト スムーズスクロール パッチ

MSX2 版ドラゴンクエスト スムーズスクロール パッチ
==================================================

MSX2 専用版ドラゴンクエストの ROM イメージに当てると、V9958 (MSX2+、turbo R)
で、フィールドや町を 1 ドットずつ滑らかにスクロールするようになるパッチです。

ゲームの ROM イメージは含まれていません。各自で用意してください。
非公式のパッチです。使用は自己責任でお願いします。
実機での確認はまだしていません (エミュレータ openMSX での確認のみ)。


■ 使い方

  python dq1patch.py 元のROM [-o 出力] [--frames N] [--msk M]

  例: python dq1patch.py DQ1.rom
      → 同じフォルダに DQ1_smooth.rom (256KB) ができる

  - Python 3.8 以上が必要です (標準ライブラリだけで動きます)
  - 元の ROM は MSX2 専用版 (128KB) です
  - できる ROM は 256KB の ASCII8 メガ ROM です。エミュレータでは ROM の
    種類に ASCII8 を指定してください

  オプション
  --frames    1 歩のフレーム数: 8 / 10 / 12 / 14 / 16 (省略時 16。ファミコン版と
              同じ速さ。元の MSX2 版は約 10)
  --msk       横スクロール中に左端に出る 0〜7 ドットの乱れの隠し方
              (V9958 の R#25 MSK): 0 = 隠さない、1 = 歩いている間だけ隠す、
              2 = 常に隠す (省略時)


■ 主な変更点

  - 元の MSX2 版は、1 歩ごとに画面全体を VDP でコピーして 1 マス分を一度に
    動かしていました。このパッチでは、歩いている間の表示を 512x256 の面
    (V9958 の横スクロール) に切り替え、毎フレーム少しずつ動かします
    (1 歩 16 フレームなら 1 フレームに 1 ドット)
  - NPC もゲームの中の本当の位置で 1 ドット単位に表示します
    (元の MSX2 版はマス単位で表示)
  - フィールドの下の 4 ラインにも背景を表示します
  - V9938 (MSX2) では元のままの動きです


■ 動作確認

  - エミュレータ openMSX: Panasonic FS-A1ST (V9958)、C-BIOS MSX2 (V9938)
  - 城・町・フィールドでの移動、窓とコマンド、マップの切り替え、戦闘
  - 洞窟 (灯りの範囲だけを描く場面) は元の処理のまま
